# 🏙️ SmartTwin 2.0

> Edge AI Digital Twin for Smart Municipal Infrastructure

SmartTwin 2.0 is a modular smart-city platform that combines IoT, Edge AI, Digital Twins, and citizen participation to monitor municipal infrastructure in real time.

The project is being developed as a final-year Electronics and Communication Engineering (ECE) project and follows a software-first approach before hardware deployment.

---

## 🎯 Project Objective

Develop an intelligent municipal monitoring system capable of:

- Monitoring critical infrastructure
- Predicting failures using AI
- Visualizing city assets through a Digital Twin
- Integrating citizen complaints with sensor data
- Enabling predictive maintenance

---

# 🚀 Current Module

✅ Virtual Sensor Simulator (VSS)

The Virtual Sensor Simulator emulates IoT devices without requiring physical hardware.

Supported assets include:

- Streetlights
- Water Pipelines
- Waste Bins
- Public Toilets

Features:

- Live sensor simulation
- Random data generation
- Fault injection
- Sensor health indicators
- JSON payload generation
- Simulation logs
- Dashboard KPIs
