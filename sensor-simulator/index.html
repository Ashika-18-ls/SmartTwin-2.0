About this Simulator

This Virtual Sensor Simulator emulates four ESP32-based municipal sensor nodes for SmartTwin 2.0 — An Edge AI Digital Twin for Smart Municipal Infrastructure.

Every "Send Data" action emits the exact JSON schema the real hardware nodes will transmit, so the backend and AI pipeline can be developed before deployment.
